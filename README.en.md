# Frontend Learning Notes

> Vue.js Source Code Analysis | Frontend Interview Guide | Engineering Practice

This project is a comprehensive frontend learning system, covering Vue.js source code analysis, JavaScript core knowledge, engineering practices, TypeScript, and high-frequency topics for frontend interviews.

## 📖 Quick Navigation

- **[Vue Source Code Study](docs/vue/index.md)** - In-depth analysis of Vue 2/3 source code
- **[Frontend Interview Questions](docs/interview.md)** - Common Vue 2 interview topics
- **[TypeScript Interview Questions](docs/ts-interview.md)** - Common TypeScript interview topics
- **[JavaScript Core](docs/frontend/js-core/index.md)** - Prototype chain, closures, event loop, Promise
- **[Engineering Practice](docs/frontend/engineering/index.md)** - Webpack, Vite, Babel, ESLint
- **[Performance Optimization](docs/frontend/performance/index.md)** - First screen loading, rendering performance, caching strategies

## 🗺️ Suggested Learning Path

### Beginner Phase
1. JavaScript Core Fundamentals (Prototype Chain, Closures, This Binding, Event Loop)
2. TypeScript Basic Types and Utility Types
3. Basic Vue Usage

### Intermediate Phase
1. Principles of Vue 2 Reactivity System
2. Virtual DOM and Diff Algorithm
3. Template Compilation Process
4. Lifecycle and Instance Initialization

### Advanced Phase
1. Vue 3 Composition API
2. Vue 3 Reactivity System (Proxy)
3. Compilation Optimization and Runtime Optimization
4. Deep Dive into Engineering (Build Tool Principles)
