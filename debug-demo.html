📦 第一部分：响应式系统 — Observer / Dep / Watcher

1observe() 入口 → Observer 构造 → walk() → defineReactive()

调用链: observe(data) → new Observer(data) → this.walk() → defineReactive(obj, key)src/core/observer/index.js

每个属性用 Object.defineProperty 劫持 getter/setter。每个属性在闭包中持有一个 const dep = new Dep()。

2依赖收集：Watcher 构造 → pushTarget → getter → Dep.depend()

调用链: new Watcher(vm, renderFn) → pushTarget(watcher) 将 Dep.target 指向当前 watcher → 执行 renderFn()，模板中读取 this.xxx 触发 proxy getter → 触发属性 getter → dep.depend() → Dep.target.addDep(dep) → dep.subs 添加 watcher，watcher.deps 添加 dep（双向记录）src/core/observer/watcher.js

Track 依赖收集：data 属性 ↔ Dep ↔ Watcher 三者建立了关联图。

3派发更新：setter → dep.notify() → watcher.update() → 异步队列

调用链: 修改 data.xxx = newVal → 触发 setter → dep.notify() → 遍历 subs 中每个 watcher 调用 watcher.update() → queueWatcher(watcher) 推入异步更新队列 → nextTick(flushSchedulerQueue) 微任务批量执行 → watcher.run() → this.get() 重新求值 → 触发 patch 更新 DOMsrc/core/observer/scheduler.js

Trigger 派发更新：数据变更 → setter → notify → 异步批量更新。

🖼 第二部分：组件渲染 — VNode 创建 → DOM 渲染

4_render() → VNode 创建：h() / createElement → new VNode()

调用链: vm._render() → 执行 render(h) → h('div', {...}, [children]) → createElement() → new VNode(tag, data, children)src/core/vdom/create-element.js + vnode.js

VNode 是纯 JS 对象，描述 DOM 结构：{ tag, data, children, elm, text, key }

5_update() → patch()：首次渲染（VNode → 真实 DOM）

调用链: vm._update(vnode) → patch(oldVnode, vnode) → 首次渲染时 oldVnode 是真实 DOM 容器 → createElm(vnode) 递归创建真实 DOM → insert(parentElm, vnode.elm) 将 DOM 插入页面src/core/vdom/patch.js

首次挂载核心步骤：createElm → createChildren → invokeCreateHooks → insert

⚡ 第三部分：视图更新 — Diff 算法 & 异步队列

6视图更新：数据变更 → Watcher.run() → _update → patch（对比更新）

调用链: 数据变更触发 watcher.run() → vm._update(vm._render()) → patch(oldVnode, newVnode) → sameVnode(old, new) 判断是否相同节点（key + tag）→ 相同则 patchVnode()，不同则暴力替换src/core/vdom/patch.js

7patchVnode() → updateChildren()：双端 Diff 算法

核心 diff 策略：oldStartIdx→←oldEndIdx 和 newStartIdx→←newEndIdx 四个指针，每次循环做 4 种比较（头头 / 尾尾 / 头尾 / 尾头），命中后移动指针，未命中则 key 查找。时间复杂度 O(n)。src/core/vdom/patch.js updateChildren()

8nextTick 异步队列：queueWatcher → flushSchedulerQueue

多次数据变更合并为一次 DOM 更新：watcher.update() 不立即执行，调用 queueWatcher(watcher) 去重后推入队列 → nextTick(flushSchedulerQueue) → Promise/MutationObserver 微任务批量执行所有 watcher.run()src/core/observer/scheduler.js

重要 连续修改 3 次数据 → 只触发 1 次 patch！
