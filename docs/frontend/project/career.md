# 线上排查 & 团队贡献

## 线上问题排查框架

```
1. 问题现象（用户反馈 / 监控报警）
2. 排查过程（定位思路、工具）
3. 根因分析（为什么出现）
4. 解决方案（怎么修）
5. 预防措施（如何避免复发）
```

### 案例模板

```
问题：用户反馈页面白屏，Safari 上 Chrome 正常

排查：
  ① Sentry 报错：Unexpected token '?'
  ② 定位：可选链 ?. → Safari 14 不支持
  ③ babel targets 检查 → 没覆盖 Safari

根因：babel targets 未覆盖 Safari 旧版本，可选链未转译

修复：
  ① targets 加 "iOS >= 12"
  ② CI 加 browserlist 检查
  ③ 核心页面加 E2E 多浏览器

预防：
  lint-staged 禁止高版本语法（除非 babel 确保转译）
```

## 团队贡献

> 面试官想看你不是"接需求写代码"，而是能推动团队前进。

**可以聊的方向**：

```yaml
组件封装：
  封装了 XX 个业务组件 → NPM 包 → 被 Y 个项目复用
  → 统一 UI 体验，减少重复开发

脚手架/CLI：
  写了内部脚手架 → 新项目初始化 2天 → 30分钟
  → 统一项目结构 + 工具链配置

规范落地：
  ESLint + Prettier + Husky 引入
  → 代码风格统一率 60% → 95%
  → 减少 CR 中的格式争议

Code Review：
  如何做 CR？
  发现过什么典型问题？
  推动了哪些改进？

技术分享：
  组织技术分享 N 次
  推动 Vue 2 → Vue 3 升级
  带新人成长

文档建设：
  搭建团队 Wiki / 组件文档站
  → 减少重复问题，提升新人上手速度
```
